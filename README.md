# Orbit — Connect Ideas

**CXT453: Design Process and Perspective | Assignment 2**  
**Question 1:** Develop a UI for a Social Media Website and Chat  
**SDG Alignment:** SDG 9 — Industry, Innovation and Infrastructure

## Project Overview

Orbit is a responsive social media website UI concept designed to help students and communities share ideas, discover discussions, and communicate through a simple feed and chat interface. The project explores how an accessible digital platform can support collaboration and community innovation, in line with SDG 9.

## Main Features

- Responsive home feed and story strip
- Create and publish text posts
- Like and unlike posts
- Expand comments and add comments
- Save and unsave posts
- Search posts and topics
- Feed filters and section navigation
- Follow and unfollow suggested users
- Trending tags that can populate the search field
- Chat interface with selectable contacts and a message-sending prototype
- Keyboard shortcut (`Ctrl`/`Cmd` + `K`) to focus the search field

## Technology Stack

- **HTML5** — page structure and content
- **CSS3** — layout, styling, and responsive behaviour
- **JavaScript** — client-side interactions

## Project Files

- `index.html` — website structure and UI content
- `styles.css` — visual design and responsive layout
- `app.js` — front-end interactions

## Running the Project

1. Download or clone this repository.
2. Open `index.html` in a modern browser such as Chrome, Edge, or Firefox.
3. Internet access is required for externally hosted fonts and profile images. The main UI runs in the browser and does not require a backend server or database.

## Design Approach

Orbit uses a clean feed-based layout, a consistent purple accent colour, neutral backgrounds, readable typography, and card-based sections to establish visual hierarchy. Navigation and interaction controls are arranged around common social media tasks so users can find posts, interact with content, and open the chat interface.

## Connection to SDG 9

SDG 9 focuses on industry, innovation, and infrastructure. Orbit connects to this goal by presenting a digital communication concept where people can exchange ideas, participate in discussions, and collaborate through an accessible online interface.

## Scope and Limitations

This project is a front-end prototype created for an academic UI design assignment. It does not implement user authentication, server-side storage, a database, or real-time messaging. Posts, comments, follows, and messages are handled only within the current browser session; they are not persisted to a backend.
