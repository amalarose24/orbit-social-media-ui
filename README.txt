WHAT IS INCLUDED
- index.html: responsive social media UI
- styles.css: visual styling and responsive layout
- app.js: front-end interactions

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, or Firefox).
3. Internet access is needed for Google Fonts and the remote profile photos. The UI itself runs locally; it does not require a server or database.

INTERACTIONS TO DEMONSTRATE
- Responsive home feed and story strip
- Create and publish a post (stored in the current page session only)
- Like/unlike posts and update like counts
- Expand comments and add comments
- Save/unsave posts
- Search post content and topics
- Feed filters and navigation
- Follow/unfollow suggested people
- Trend tags populate the search field
- Direct messages dialog with selectable contacts and send-message prototype
- Keyboard shortcut Ctrl/Cmd + K focuses search

DESIGN / RUBRIC ALIGNMENT
- Concept: Orbit is a student/community-oriented social platform designed around sharing ideas, collaboration, and innovation. This relates to SDG 9 through digital communication infrastructure and community innovation.
- UI/visual design: consistent purple accent, neutral canvas, clear hierarchy, typography, spacing, cards, and responsive breakpoints.
- Functionality: navigation, search, feed filters, post composer, reactions, comments, saves, follow controls, and chat prototype.
- Content/communication: clear labels, community posts, trends, people suggestions, and a concise SDG 9 message.
- Presentation: files are separated and named clearly; responsive desktop/tablet/mobile layout.

IMPORTANT LIMITATION
This is a front-end prototype, not a production social network. Posts/comments/follows/messages are not saved to a database, real-time messaging is simulated, and authentication/security are not implemented. Do not claim otherwise during evaluation.
